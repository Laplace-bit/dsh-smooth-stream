dsh-smooth-stream

dsh-smooth-stream 为 DeepSeek Harness 带来流畅的流式渲染和丝滑滚动：文字、Markdown、代码块、表格以及工具结果随着输出自然呈现，内容增长时页面平稳跟随。
dsh-smooth-stream brings fluid streaming rendering and silky scrolling to DeepSeek Harness: text, Markdown, code blocks, tables, and tool results appear as the reply arrives while the page follows the growing content.

效果 Preview

核心体验 Core experience

  • 流畅渲染

    文字边到边呈现，Markdown 结构持续更新，标题、列表、代码块和表格保持自然的阅读状态。

  • 丝滑滚动

    内容逐步变高时，页面沿连续的滚动轨迹平稳跟随，视线始终贴着正在生成的内容。

  • 统一过渡

    换行、代码块、表格和工具结果使用一致的过渡方式，正文、思考过程与工具输出衔接自然。

  • 自适应节奏

    渲染速度会根据输出速度和待显示内容调整，让慢速输出从容呈现，快速输出及时跟上。

安装 Install

pnpm dsh plugin --profile web add dsh-smooth-stream

npm 包自带预构建的 lib/，不需要 pnpm ≥10 的构建脚本授权；如果 PATH 上已经有 dsh，可直接运行 dsh plugin --profile web add dsh-smooth-stream。然后 pnpm dsh web 启动，Host 日志出现 [dsh-smooth-stream] plugin loaded! 即成功。

卸载：pnpm dsh plugin --profile web remove dsh-smooth-stream（或 dsh plugin --profile web remove dsh-smooth-stream）。

用户设置 User settings

在 Web 界面打开 设置 → 插件 → 插件配置，在 丝滑流式（Smooth stream）卡片中切换「自动展开思考」。

  • 开（默认）

    思考块在流式时自动展开，思考结束后收起。Reasoning auto-expands while streaming, then collapses when it ends.

  • 关

    思考块保持折叠；仍可手动点开，流式状态不会抢回控制。Reasoning stays collapsed and can still be opened by hand.

这是用户级的持久化偏好，改完即生效，无需重启；它写入 DeepSeek Harness 的用户设置文档，不是插件的组合配置。

常见问题 FAQ

什么是 dsh-smooth-stream？

为 DeepSeek Harness（dsh）Web UI 带来流畅的流式渲染和丝滑滚动。文字、Markdown、代码块、表格以及工具结果会随着输出自然呈现；内容逐步增长时，页面平稳跟随，整轮回复保持连贯的视觉节奏。

怎么安装 dsh 插件？

在 DeepSeek Harness 源码目录运行 pnpm dsh plugin --profile web add dsh-smooth-stream（或 PATH 上的 dsh plugin --profile web add dsh-smooth-stream）。

Is it an official DeepSeek plugin?

No. It is independently maintained, MIT-licensed software for the DeepSeek Harness (dsh) Web UI and is not affiliated with DeepSeek.

支持 prefers-reduced-motion 吗？

支持。系统开启减少动态效果时直接显示完整文本，不接管跟随；帧率低于 30 fps 且回复在屏外时揭示自动暂停。

怎么设置自动展开思考？

在 设置 → 插件 → 插件配置 的 丝滑流式（Smooth stream）卡片中切换「自动展开思考」。关闭后思考块保持折叠，仍可手动展开；该偏好即时生效，无需重启。

怎么更新 dsh-smooth-stream？

npm 安装的 profile 可运行 dsh plugin --profile web update dsh-smooth-stream，或在插件卡片中点击更新并重启 Harness。link: 和 file: 本地开发安装的更新按钮会保持禁用。

Can it be installed from npm?

Yes. dsh-smooth-stream is published to npm; dsh plugin --profile web add dsh-smooth-stream installs the prebuilt package.
